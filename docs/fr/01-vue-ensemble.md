# 1. Vue d’ensemble de Kamino KLend

KLend est un marché de prêt open source pour Solana. Le programme Anchor gère les dépôts, les emprunts, les intérêts, les garanties et les liquidations.

Les comptes de marché et de position séparent la configuration globale des soldes utilisateurs. Cette organisation est essentielle dans le modèle de comptes explicites de Solana.

Le parcours suit les instructions du programme, les contraintes de capacité et les calculs de valeur. Il documente aussi les frontières entre programme, oracle et client.

Aucune installation, compilation ou exécution n’a été réalisée.
